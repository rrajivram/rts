rts: reference counting vs tracing GC

Thesis: freeing memory as soon as it is dead (scope arenas, reference counting) keeps memory use close to what the program needs, steady and predictable, without collection pauses, where a tracing GC trades memory and pauses for throughput. The same engine and compiled code, built two ways: reference counting with scope arenas and a cycle collector (the default), and a tracing mark-sweep GC (--features gc). Typed Are-We-Fast-Yet ports and a request loop; output matches Node byte for byte. Commit 2f42f2f, 2026-11-20.
