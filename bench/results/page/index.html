How these numbers are measured

One engine, four memory strategies: scope arenas plus reference counting (the default), reference counting without arenas, reference counting without the cycle collector, and a tracing mark-sweep GC built with --features gc, which keeps no counts at all. The instructions are the same in every build.

Benchmarks are the Are-We-Fast-Yet suite ported to typed TypeScript; their output matches Node's byte for byte. Times are each harness's own measurement (start-up excluded), medians of 3 runs on an Apple M-series machine. RSS is the process maximum.

The instruction profile counts every execution exactly, and samples time from a separate thread every 20 µs. Reference-count updates are counted in the profiling build only.

Reproduce with bench/modes.py, bench/latency.py and bench/profile.py in the rts repository; bench/results/build.py turns their output into this page's files.
